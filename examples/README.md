# Worked examples

These are **examples**, written to show how the Fable Forge method reads on a real page. Each one is reconstructed from a public concept study in Dainer's studio collection at [dainer-ai-showcase.vercel.app/sites/](https://dainer-ai-showcase.vercel.app/sites/). They are not the original build logs, and they do not claim the page was built only with this skill.

Every "acceptance evidence" line below was checked on 23 September 2026 against the live page with Playwright. The businesses are concept studies, not real businesses, and each page labels itself as a concept study in its footer. Any addresses shown are made up.
