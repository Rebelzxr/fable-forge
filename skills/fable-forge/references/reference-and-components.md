# References and components

Use this reference when a job provides a site reference, visual asset, or component library. Inspect only what the current surface needs.

## Observe before translating

Record source URL or local path, access date, route, viewport, and state. State what was actually visible and what remains inferred. For a meaningful reference, capture the visitor's task, input, feedback, navigation, responsive invariant, and one transferable principle. A static screenshot supports visual observation; it does not prove hover, touch, keyboard, scroll, loading, or error behavior.

Choose references for fit to this audience and page job. Do not require a fixed count or numerical fit score. If materially different variants are requested, vary composition, hierarchy, media role, interaction, or conversion path. A palette or prop swap alone is a weak variant.

## Harvest a useful component

For a form, table, navigation, modal, search, or other interactive component, inspect its relevant state family: default, focus, active/selected, disabled, loading, empty, error, success, close/escape, and return focus. Do not force irrelevant states onto a static section. Record how the component behaves on keyboard and touch, and how it changes on narrow screens.

Reuse an existing local component first when it serves the job. A third-party module is a candidate only when its license, usage rights, dependencies, compatibility, and maintenance fit the project. Read the implementation and terms before copying; do not assume a public catalogue grants code or asset rights. Preserve origin and license notices. A visible reference may inspire a behavior without contributing code.

Translate any approved component into the project's tokens: colour and semantic states, typography, spacing, radius, surface treatment, motion, and density. Keep structural or accessible behavior that works; change brand styling, copy, and media. Check that the result looks and behaves as one system in the actual page, without arbitrary hard caps on radii, shadows, elevation, type ratios, or component counts.

The destination's content and task outrank a reference's novelty. Preserve authentic client assets where authorized. Never present another brand's logos, testimonials, screenshot, or trade dress as this project's proof.
